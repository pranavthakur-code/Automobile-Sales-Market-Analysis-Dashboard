# Automobile Sales & Market Analysis Dashboard

## Project Overview
This Power BI dashboard provides insights into automobile sales performance, vehicle characteristics, and pricing trends.

## Dashboard Pages

### 1. Automobile Sales & Market Analysis Dashboard
- Total Cars Sold
- Average Selling Price
- Brand Analysis
- Sales Trends by Year
- Transmission Analysis

### 2. Vehicle Characteristics Dashboard
- Vehicle Models
- Body Types
- Transmission Types
- Color Analysis
- State-wise Distribution

### 3. Vehicle Price Insights Dashboard
- Highest & Lowest Average Brand Price
- Average Selling Price
- Price by State
- Price by Model
- Odometer vs Selling Price Analysis

## Tools Used
- Power BI
- Data Modeling
- DAX
- Data Visualization
